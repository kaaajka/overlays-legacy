# Production 2.2 — reaction lettering

Built-in imagegen produced two new transparent PNGs from the supplied banner as a style reference. Original donation clips, music and community emotes were not regenerated. Donor text remains semantic Poppins; only reaction lettering uses these raster assets. The original outputs were copied without pixel edits.

- `public/assets/donations/brand/omg-handwritten.png`: Donate3, 200×80 CSS box.
- `public/assets/donations/brand/holy-moly-handwritten.png`: Donate5, two CSS windows over the same asset, one per word.

## Exact prompts

### OMG!

Create a new transparent-background PNG lettering asset for a Kaaajka Twitch rodent reaction overlay. Input reference image is only a style reference: use the loose informal white handwritten lettering in the supplied Kaaajka banner (the left-side !discord,!eneba script). Exact sole text: "OMG!" Four visible glyphs, capital O M G exclamation. Draw by hand with soft thick matte white ink, playful uneven baseline and subtly variable stroke width, expressive comic surprise, slightly leaning with open counters; thin dark plum ink contour plus a fine warm peach outside contour for clarity on crowded gameplay. Fill most of a wide landscape canvas with lettering, modest transparent padding. Flat lettering only, no shadow/glow/gradient, no objects/mascot, no banner/photography, no background or checkerboard baked in. Preserve genuine alpha.

### HOLY MOLY

Create a new transparent-background PNG lettering asset for a Kaaajka Twitch arms-wide ovation overlay. Input reference image is only a style reference: use the loose informal white handwritten lettering in the supplied Kaaajka banner (the left-side !discord,!eneba script). Exact sole text: "HOLY MOLY" two words on ONE LINE, generously separated. Draw by hand with soft thick matte white ink, playful uneven baseline and subtly variable stroke width, enthusiastic open arms energy, rising HOLY and returning MOLY, open counters; thin dark plum ink contour plus a fine warm peach outside contour for clarity on crowded gameplay. Fill most of a very wide landscape canvas with lettering, modest transparent padding. Flat lettering only, no shadow/glow/gradient, no objects/mascot, no banner/photography, no background or checkerboard baked in. Preserve genuine alpha.

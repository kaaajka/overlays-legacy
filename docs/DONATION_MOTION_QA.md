# Motion engine verification — 2026-10-07

## Automated evidence

- Vitest: 267 passing tests in 26 suites. Baseline: 219 passing tests plus a broken stale template suite. New tests cover music clock/output timestamps, authored cue validation, feature fallback/latching, bindings, deterministic random details, intensity/quality, source-node lifecycle, bounded decode/watchdog, abort/cleanup and FIFO sequence integration.
- Playwright: 16 passing scenarios. All eight treatments captured at hero −50ms, exact cue, +50ms and information; measured amount/name separation; backward/forward determinism; canvas alpha coverage; SAFE with unavailable WebGL; audio decode failure; PageChannel FIFO fixtures; full long-message scroll; context loss; scheduled calibration flash; quality/seed remounts; pause/restart and a busy-main-thread stall.
- In the final captured run, audio position advanced from approximately 0.73s to 1.25s across a 500ms visual stall. This demonstrates catch-up to the audio clock, not a measurement of OBS output latency.
- Lint, typecheck and production build pass. Formatting passes for changed motion sources. Global format check has 34 preexisting legacy-file differences.
- Production contains no Motion Studio bundle. Legacy donation effect Sass is excluded from the live entrypoint; source remains as reference. Final built CSS is about 361 kB before gzip versus 434 kB baseline; the bundle retains animate.css and unrelated legacy event styles.

Raw local captures and clock measurements live in ignored `.motion-qa/`. They are reproducible with `pnpm motion:qa`. These images are generated by a Chromium software renderer; they do not certify OBS, an RTX 3070 or the visual feel during audible playback.
